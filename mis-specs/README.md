# 📝 Mis Specs (Lenguaje Natural)

Acá van tus ideas y specs escritas **en tu idioma**, como se te ocurran.

## Reglas

1. Escribí como se te venga: preguntas, dudas, requisitos, lo que sea
2. El agente se encarga de convertir eso a formato Speckit estructurado
3. Cuando Speckit se actualice, el agente te avisa y refleja los cambios acá

## 📄 Documento Maestro

**`CONOCIMIENTO.md`** es el archivo más importante. Contiene TODO el proyecto:
- Stack tecnológico completo
- Reglas de diseño (Constitución)
- Features implementadas y planeadas
- Fórmulas financieras
- Arquitectura
- Convenciones de código
- Glosario

Editá `CONOCIMIENTO.md` directamente cuando quieras cambiar reglas, agregar consideraciones, o actualizar el estado del proyecto.

## Cómo Empezar

1. Leé `CONOCIMIENTO.md` para entender el estado completo del proyecto
2. Mirá el ejemplo en `../.obsidian/.obsidian/ejemplo-spec-natural.md` para ver el formato
3. Creá un archivo nuevo acá, ej: `mi-idea-genial.md`, y escribí tu idea
4. El agente convierte tu nota a formato Speckit estructurado
